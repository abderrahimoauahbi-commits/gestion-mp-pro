## Écrire un document imprimable (D3 bon fournisseur, D5 feuille de comptage, D8 bilan)

```python
from gestion_mp_pro.documents import rendu

html = rendu.rendre(
    "bon_commande.html",            # dans documents/gabarits/
    societe=rendu.societe(s),       # réglages « Société » lus en base
    titre="BC-2026-0012",           # <title> de l'onglet
    langue="en",                    # "fr" (défaut) ou "en" : mots du papier et filtres
    paysage=False,                  # True : A4 paysage (feuille de comptage)
    bon=donnees,                    # vos données, déjà calculées par votre service
)
return rendu.reponse(html)          # HTMLResponse inline + CSP qui permet « Imprimer »
```

Route : `response_class=HTMLResponse`, `responses={**reponses(401, 403, 404), **rendu.REPONSES_HTML}`.

Gabarit :

```jinja
{% extends "_papier_a_en_tete.html" %}
{% block style %}.ma-classe { … }{% endblock %}
{% block contenu %}<h1>Purchase order</h1> … {{ ligne.kilos|kg }} {{ bon.date|date }}{% endblock %}
```

- Le papier (A22) est posé par la base : raison sociale en rouge (19 pt, initiale 28 pt), secteur
  (sous la raison sociale), forme juridique et capital, « SIÈGE SOCIAL » / « HEAD OFFICE » +
  adresse, ville, téléphone ; pied : « BANQUES » / « BANKS » + banques (le réglage les sépare par
  « · »), puis « ICE : … R.C : … N.I.F : … C.N.S.S : … PATENTE : … ». Lignes vides omises.
- Sans raison sociale : bandeau « En-tête non réglé : … » à l'écran seulement (classe
  `ecran-seulement`) ; le bloc `en_tete_non_regle` en change la phrase (D3 : « … en tête du bon. »).
- Plusieurs feuilles (une par magasin) : redéfinir `{% block pages %}` et, pour chaque feuille,
  `{% import "_papier.html" as papier %}` puis `{% call papier.feuille(societe, mots) %}…{% endcall %}`.
- Filtres (langue du document) : `nombre(d, dmax)`, `kg`, `kg_entier`, `m2`, `date` ; et
  `horodatage`, `montant(devise)`, `montant_precis(devise)`, `prix`, `cours`, `pourcent`, `part`.
  Ce sont ceux de `documents/format.py`, jumeau de `frontend/src/lib/format.ts` (espace insécable,
  « − », jamais « -0 », ARRONDI d'Excel) ; en anglais « 1,234.5 » et « 08 Oct 2026 » (D3 : ne pas
  redoubler `nombre_en`/`date_en` dans `anglais.py`, qui garde les conditionnements).
- Classes communes de `_impression.css` : `table.donnees` (en-tête répété, `.n` nombres à droite),
  `.cadre`, `.note`, `.lib`, `.sous-titre`, `.vide`, `.saut`, `h1`, `h2`. Tailles en points.
- Le bouton « Imprimer / enregistrer en PDF (A4) » est en français dans tous les documents (il ne
  s'imprime pas). Son script est permis par son empreinte : `rendu.reponse` pose la CSP ; **aucun
  autre script** dans un gabarit.
