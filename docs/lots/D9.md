## Écrire un document imprimable (D3 bon fournisseur, D5 feuille de comptage, D8 bilan)

```python
from gestion_mp_pro.documents import rendu

html = rendu.rendre(
    "bon_commande.html",            # dans documents/gabarits/
    societe=rendu.societe(s),       # réglages « Société » lus en base
    titre="BC-2026-0012",           # <title> de l'onglet
    langue="en",                    # "fr" (défaut) ou "en" : mots du papier et filtres
    paysage=False,                  # True : A4 paysage (feuille de comptage)
    bon=donnees,                    # vos données, déjà calculées par votre service
)
return rendu.reponse(html)          # HTMLResponse inline + CSP qui permet « Imprimer »
```

Route : `response_class=HTMLResponse`, `responses={**reponses(401, 403, 404), **rendu.REPONSES_HTML}`.

Gabarit :

```jinja
{% extends "_papier_a_en_tete.html" %}
{% block style %}.ma-classe { … }{% endblock %}
{% block contenu %}<h1>Purchase order</h1> … {{ ligne.kilos|kg }} {{ bon.date|date }}{% endblock %}
```

- Le papier (A22) est posé par la base : raison sociale en rouge (19 pt, initiale 28 pt), secteur
  (sous la raison sociale), forme juridique et capital, « SIÈGE SOCIAL » / « HEAD OFFICE » +
  adresse, ville, téléphone ; pied : « BANQUES » / « BANKS » + banques (le réglage les sépare par
  « · »), puis « ICE : … R.C : … N.I.F : … C.N.S.S : … PATENTE : … ». Lignes vides omises.
- Sans raison sociale : bandeau « En-tête non réglé : … » à l'écran seulement (classe
  `ecran-seulement`) ; le bloc `en_tete_non_regle` en change la phrase (D3 : « … en tête du bon. »).
- Plusieurs feuilles (une par magasin) : redéfinir `{% block pages %}` et, pour chaque feuille,
  `{% import "_papier.html" as papier %}` puis `{% call papier.feuille(societe, mots) %}…{% endcall %}`.
- Filtres (langue du document) : `nombre(d, dmax)`, `kg`, `kg_entier`, `m2`, `date` ; et
  `horodatage`, `montant(devise)`, `montant_precis(devise)`, `prix`, `cours`, `pourcent`, `part`.
  Ce sont ceux de `documents/format.py`, jumeau de `frontend/src/lib/format.ts` (espace insécable,
  « − », jamais « -0 », ARRONDI d'Excel) ; en anglais « 1,234.5 » et « 08 Oct 2026 » (D3 : ne pas
  redoubler `nombre_en`/`date_en` dans `anglais.py`, qui garde les conditionnements).
- Classes communes de `_impression.css` : `table.donnees` (en-tête répété, `.n` nombres à droite),
  `.cadre`, `.note`, `.lib`, `.sous-titre`, `.vide`, `.saut`, `h1`, `h2`. Tailles en points.
- Le bouton « Imprimer / enregistrer en PDF (A4) » est en français dans tous les documents (il ne
  s'imprime pas). Son script est permis par son empreinte : `rendu.reponse` pose la CSP ; **aucun
  autre script** dans un gabarit.

## Écrire un classeur Excel (tous les lots)

```python
from gestion_mp_pro.exports.classeur import Colonne, Feuille, classeur, filtres, reponse, titre

COLONNES = (
    Colonne("Date", lambda x: x.date, "date"),
    Colonne("Quantité (kg)", lambda x: x.kg, "kg"),
    Colonne("Valeur (MAD)", lambda x: x.valeur_mad, "montant", monetaire=True),
)
entete = [titre("Stock", jour), filtres([("mots", f.q), ("du", f.du)])]
contenu = classeur([Feuille("Stock", COLONNES, lignes, entete)], voit_prix=qui.voit_prix)
return reponse(contenu, "stock", jour)     # attachment ; nom « stock-2026-10-08.xlsx »
```

Route : `response_class=Response`, `responses={**reponses(401, 403, 422), **classeur.REPONSES_XLSX}`.

- Grandeurs (`FORMATS`) : `kg` `#,##0.0`, `kg_precis` `#,##0.000`, `entier`, `m2`, `montant`
  `#,##0.00`, `prix` `#,##0.00##`, `cours` `0.0000`, `pourcent` `0.0%` (une fraction),
  `date`, `horodatage` ; ou un format Excel écrit tel quel.
- Valeurs (`cellule`) : `Decimal` → nombre ; `date` → vraie date ; instant → heure de l'usine sans
  fuseau ni microsecondes ; booléen → « oui » / vide ; énumération → sa valeur ; texte sans
  caractères de contrôle ; `=`, `+`, `-`, `@` en tête → texte (jamais une formule).
- En-tête gras sur fond gris, figé (et la 1ʳᵉ colonne au-delà de 4 colonnes), filtre automatique
  sur les lignes (aucun sur une feuille vide), largeurs calculées (≤ 50) ; onglets assainis et
  uniques. `GRAVITES` traduit les gravités des contrôles. `exporte_le(...)` pour une liste sans
  date de référence (« Matières — exporté le 08/10/2026 »).
- **Filtres = écran** : la route d'export prend la **même dépendance de filtres** que la liste
  (exemple : route 52, `FiltresDep` de la route 49) ; l'essai compare les lignes des deux.
- **Aucun prix pour L (ni T)** : `monetaire=True` retire la colonne quand `voit_prix` est faux ;
  dans ce cas, un titre qui dit prix, montant, valeur, coût, cours, CMUP, TVA, frais, MAD… sans
  `monetaire=True` lève `ValueError` (vu par vos essais).

## Décisions

1. **Étiquettes : une par page de 100 × 70 mm** (`@page { size: 100mm 70mm; margin: 4mm }`),
   comme Gestion MP en service et ECRANS-PRO (« identique ») ; API-PRO 114 écrit « HTML A4 ».
2. **Langue du papier** : `rendre(..., langue="en")` donne « HEAD OFFICE » / « BANKS » (consigne du
   coordinateur, comme Gestion MP corrigé) ; ECRANS-PRO 4.29 disait que « SIEGE SOCIAL » et
   « BANQUES » restaient en français sur le bon. D3 choisit ; à trancher dans ECRANS-PRO.
   « SIÈGE SOCIAL » prend son accent.
3. Le **secteur** s'imprime sous la raison sociale (A22), en italique.
4. **Impression sans coque** : page autonome, barre « Imprimer » écran seulement ; son script est
   permis par une CSP propre au document (`script-src 'sha256-…'`, posée par `rendu.reponse`).
   **X1** : Caddy ne doit pas remplacer la CSP de l'application (sinon le bouton ne marche plus).
5. **Pied du papier** en bas de chaque feuille imprimée (`position: fixed`), une place lui étant
   gardée sur chaque feuille par le pied répété d'un tableau de mise en page (le texte ne passe
   jamais dessous) ; à l'écran, en bas de la feuille A4 simulée.
6. Étiquettes : QR sans marge (comme Gestion MP : la marge de l'étiquette en tient lieu),
   correction M, titre du SVG = l'adresse ; alerte « localhost » à l'écran seulement ; lots
   inconnus dits « Ignorés (lots inconnus, sans étiquette) : … » à l'écran seulement ; aucun lot
   connu (ou `?lots=` vide) → page HTML 404 « Aucun lot à étiqueter. » sans bouton.
7. Journal exporté : colonnes Quand, Par, Rôle (libellé), Action, Sur, Fiche n°, Numéro, Détail,
   Avant, Après (« champ : valeur · … », nombres à la française) ; pour T, les prix des
   changements sont vidés (« prix : — »), comme dans la réponse JSON.
