## Conception du vérificateur d'héritage

- Une preuve `fichier::fonction` de `ESSAIS.md` est **couverte** par un essai PRO si : (1) une
  citation exacte `fichier::fonction` est dans un essai (docstring), (2) le **nom de fonction** est
  cité ailleurs (preuve déplacée ou « … » résolu vers un autre fichier), ou (3) elle est dans le
  relevé `COUVERTURE` du script — un essai PRO reformulé, **dont l'existence est vérifiée** (le
  relevé ne peut pas pourrir sans faire échouer le script).
- Résultat : **289 couvertes** (257 exactes, 13 par le nom, 19 relevées). Les 19 relevées sont des
  essais PRO au nom reformulé (ex. `test_stock_et_valeur_en_kilos` →
  `moteur/test_metre.py::test_stock_valeur_et_cmup_en_kilos`) ; la liste est dans le script.
