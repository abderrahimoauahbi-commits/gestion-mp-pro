# Lot S2 — sécurité, audit, socle métier transverse : ce que les lots suivants doivent savoir

Branche `lot-S2`. **Version provisionnelle** (interface stable : `droit()`, filtre des prix,
fabrique de comptes, journal, numérotation, période) ; complétée en fin de lot.

## Déclarer les droits d'une route

```python
from gestion_mp_pro.securite import C, D, A, L, T, TOUS, QuiDep, droit, exiger

@routeur.get("/lots", response_model=list[LotResume], dependencies=[droit(*C)],
             summary="…", responses=reponses(401, 403))
def lister(qui: QuiDep, s: SessionDep) -> list[LotResume]: ...
```

- `droit(*roles)` rend un `Depends` : **toute** route de l'API le porte, sauf les six publiques
  (`securite.PUBLIQUES` : 1, 2, 8, 9, 10, 22). Aucun passe-droit : nommer `D` partout où la
  direction passe ; `T` (administrateur) seulement sur les routes techniques.
- `QuiDep` = la personne connectée, typée `services.comptes.Acteur` (id, identifiant, nom, role,
  requete, adresse, session, appareil_id, `voit_prix`) ; même dépendance que
  `api.dependances.ActeurDep` (un seul calcul par requête). Les services reçoivent cet `Acteur`.
- 401 « Connectez-vous pour continuer. » sans session ; 401 `compte_inactif` « Ce compte n'est
  plus actif. » ; 403 « Cette action est réservée à : responsable achats. » (KR14 mot pour mot :
  la direction n'est citée que si elle est seule permise, « la direction »).
- Droits fins (un geste dans une route ouverte à plusieurs rôles) : `exiger(qui, "approuver")`,
  `peut(qui, geste)` ; table `securite.GESTES` (voir_prix, liberer_quarantaine,
  mettre_en_quarantaine, approuver, monter, clore_periode, gerer_comptes) ; un domaine ajoute
  les siens par `securite.declarer_geste("nom", D, A)` (à l'import de son `routes.py`).
  `/moi` rend `droits` = les gestes du rôle.
- Matrice : `make matrice` (→ `backend/tests/matrice_droits.csv`, colonnes `methode;chemin;
  anonyme;direction;achats;alimentation;administrateur`, valeurs `ok`/`401`/`403`). Régénérer et
  committer le CSV dans chaque lot D ; l'essai `test_matrice_droits` échoue sinon.

## Se protéger des prix

- Rien à faire pour les réponses JSON : `securite.RouteSansPrix` (posée sur tous les routeurs
  par `communs.nouveau_routeur`) met à `null`, pour tout rôle hors `{direction, achats}`, à
  toute profondeur, les clés de `securite.CLES_MONETAIRES` : `prix*`, `montant*`, `valeur*`,
  `cout*`, `cmup*`, `budget*`, `cours*`, `taux_droits`, `economie*`, `revient*`, `tva*`,
  `droits*`, `frais*`, `devise_prix`, `*_mad`.
- Donc : **nommer** tout champ monétaire selon ces motifs (`valeur_mad`, `prix_kg`,
  `droits_douane`…) ; ne **pas** nommer ainsi un champ qui n'est pas un montant. Si c'est
  inévitable, le schéma de sortie déclare `cles_non_monetaires: ClassVar[frozenset[str]] =
  frozenset({"droits"})` (exemple : `Moi.droits`, la liste des gestes) — l'exemption vaut pour
  toute la réponse de la route.
- Une différence « champ → valeur » s'écrit avec le nom du champ en **clé** (`{"prix": 2.5}`),
  jamais `{"champ": "prix", "valeur": 2.5}` (le filtre ne verrait pas le prix).
- Documents HTML, xlsx, SVG, textes : pas filtrés ; à chaque domaine (barrière 4).
- L'essai `test_prix_masques.py` balaie toutes les routes GET en rôle alimentation sur une base
  qui contient des prix : chaque lot D y ajoute ses données (fabriques) si besoin.

## Journaliser

```python
from gestion_mp_pro.services import audit
with audit.suivre(s, qui, "modification fournisseur", fournisseur, detail=f.nom) as geste:
    fournisseur.nom = …            # seuls les champs changés vont dans avant/après
audit.creation(s, qui, "création fournisseur", f)        # après = la fiche
audit.suppression(s, qui, "suppression opération", op)   # avant = la fiche
audit.journal(s, qui, "validation réception", "reception", r.id, numero=r.numero, detail=…)
audit.verifier_version(s, fiche, version_lue, "Cette commande")  # 409 conflit_version
```

Écrit dans la transaction du geste ; colonnes techniques (`version`, `texte_recherche`,
`modifie_le`…) et secrets exclus. `qui=None` = « système ». L'historique d'une fiche est
`GET /api/historique/{objet}/{id}` (rôles de lecture par objet : `services/audit` côté S2).

## Numéroter

`numerotation.numero(s, SerieNumero.REC, jour)` → `REC-2026-0001` (`DOS` → `01/26`), dans la
transaction du geste (un refus l'annule, aucun trou), compteur verrouillé jusqu'au commit.
`deja_pris=` pour sauter les numéros saisis à la main ; `rattraper(s, serie, annee, n)` ;
`libelle_brouillon(id)`.

## Dates et période close

`periode.date_permise(s, jour)` (422 `date_trop_ancienne`, 422 `date_future`, 409
`periode_close`, messages D1–D3 mot pour mot) ; `periode.cout_hors_periode_close(s, dossier,
geste, entrees_en_plus)` (409 `cout_periode_close`) ; `periode.clore(s, qui, jour, motif)` pour la
route 26 (lot D1) ; `periode.APRES_CLOTURE.append(f)` pour figer les cours (lot D7).

## Notifications, recherche, contexte

- `notifications.notifier(s, Role.achats | utilisateur_id, texte, lien="/commandes/12",
  ton=…, cle="…", monetaire=True)` (dédoublonnée par `cle`).
- `recherche.conditions(colonne, q)` (tous les mots, `%`/`_` échappés) ; `@recherche.source(
  "genre", roles)` pour ajouter ou remplacer un genre de la recherche globale.
- `contexte.COMPTEURS["alerte_rouge"] = f(s, role)` (D8) ; `contexte.ALERTES_SERVEUR.append(f)` (D10).
