# Lot E0 — socle de l'écran : ce que les lots suivants doivent savoir

Fusionné dans main (21c4b72). `npm run verifier` : prettier, eslint, stylelint, tsc, vitest (178 essais).

## Décisions
1. Arrondi d'affichage sur l'écriture décimale la plus courte (= `Decimal(str(v))`), arrondi d'Excel (2,675 → 2,68) ; ne touche que l'affichage. Mises en forme sans `Intl`.
2. Espace insécable des milliers et avant l'unité (« 1 234,5 kg »).
3. `X-Heure-Serveur` accepté sans décalage ou avec (« +01:00 », « Z ») ; jours calculés sans le fuseau du navigateur. **S0 doit envoyer l'instant avec son décalage.**
4. TanStack Query `networkMode: 'always'` ; une écriture n'est finie qu'une fois les données relues (`meta.invalider`, `invalider: false` pour la connexion).
5. Unités `kg`, `bobine`, `palette` (codes de l'API) ; conversion vers kg au gramme ; pluriel dès 2.
6. Manifeste « Gestion MP PRO — matières premières », court « MP PRO », `start_url` `/`, thème `#17497f`.
7. Service worker : enveloppe seulement, réseau d'abord, jamais `/api`, production et contexte sûr seulement.
8. Relais Vite : 502 `{detail, code: "serveur_absent"}` si 8050 est arrêté.
9. `scripts/generer_types.sh` (adresse, fichier ou `GESTIONMPPRO_OPENAPI` ; `--verifier`).
10. Une seule assertion de type hors essais (204 dans `api.ts`).
